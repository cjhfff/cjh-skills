# Romance_Writer

**Category:** content-generation
**Target:** host
**Trigger:** `写言情` | `写小说` | `创作故事`

## Description

基于知乎热门故事套路，自动生成言情短篇小说。包含出轨、小三、复仇、逆袭等经典元素。

## Story Templates

### 模板一：原配逆袭型

**核心元素：**
- 女主被出轨→发现真相→华丽反击→小三倒霉→前夫后悔

**结构：**
```
1. 【铺垫】婚姻看似幸福，发现丈夫异常（加班变多、手机密码改了等）
2. 【发现】发现丈夫出轨对象（通常是年轻漂亮的绿茶/白莲花）
3. 【隐忍】女主假装不知，悄悄收集证据（财产、聊天记录、录音）
4. 【反击】在关键时刻揭露真相（公婆面前/社交场合/公司年会）
5. 【逆袭】离婚后过得更好（事业有成/变美变强/遇到真爱）
6. 【报应】渣男和小三互相伤害，最终倒霉
```

**示例开头：**
> "当我发现丈夫出轨时，我没有哭闹，而是默默打开手机录了音。那一刻我就知道，这场婚姻该结束了。"

---

### 模板二：真爱考验型

**核心元素：**
- 真爱遭遇阻碍→外遇诱惑→最终选择→证明真心

**结构：**
```
1. 【甜蜜】情侣/夫妻感情很好，但遭遇现实阻碍
2. 【诱惑】出现有钱/有权的第三者猛烈追求
3. 【动摇】主角内心挣扎，但最终选择真爱
4. 【考验】渣男/渣女露出真面目，证明当初选择正确
5. 【圆满】有情人终成眷属
```

**示例开头：**
> "他说爱我，却转头和别的女人进了酒店。我站在走廊尽头，手里还攥着给他买的胃药。"

---

### 模板三：因果报应型

**核心元素：**
- 出轨男/渣女→上位后变脸→遭遇报应→后悔莫及

**结构：**
```
1. 【上位】渣男为了小三离婚，抛弃原配
2. 【变脸】小三婚后露出真面目（控制欲强/拜金/虐待孩子）
3. 【报应】渣男事业下滑/身体出问题/被戴绿帽
4. 【悔恨】想起原配的好，试图挽回
5. 【打脸】原配已有新生活，比以前更幸福
```

**示例开头：**
> "他以为娶了小三就能幸福，结果不到三年，小三就卷钱跑了。"

## Plot Devices

### 经典情节

1. **捉奸在床** - 最直接的证据收集方式
2. **发现聊天记录** - 手机/电脑里的暧昧消息
3. **意外怀孕** - 小三怀孕了/原配怀孕了
4. **财产转移** - 悄悄把财产转到自己名下
5. **家庭聚会** - 在公婆/岳父母面前揭穿
6. **公司年会** - 在同事/下属面前揭穿
7. **社交媒体** - 小三晒恩爱被原配看到
8. **孩子生病** - 原配独自带孩子，渣男陪小三
9. **求原谅** - 渣男跪求复合，被原配拒绝
10. **新欢出现** - 原配遇到真爱的人

### 读者爽点

1. ✅ 小三被打脸（装不下去/被揭穿）
2. ✅ 渣男倒霉（被绿/破产/生病）
3. ✅ 原配逆袭（变美/有钱/新欢）
4. ✅ 渣男求复合被拒绝
5. ✅ 小三和渣男互相伤害
6. ✅ 原配的娘家人撑腰
7. ✅ 闺蜜/助攻神队友
8. ✅ 小三的报应（被抛弃/身败名裂）

## Output Format

**生成的故事结构：**
```
【标题】
一句话概括故事核心冲突

【人设】
女主：（性格+背景+逆袭方向）
渣男：（性格+特点+报应）
小三：（类型+特点+下场）

【开头】
100-200字，吸引读者继续阅读

【发展】
500-800字，铺垫冲突，积累情绪

【高潮】
300-500字，集中爆发，正面对决

【结尾】
100-200字，完美收官，报应/逆袭完成

【金句】
2-3句经典语录，可用于社交媒体传播
```

## Examples

### 示例一：原配逆袭

**标题：** "婆婆跪求我别离婚，我笑着打开手机录音"

**开头：**
> 我以为婚姻是两个人的事，直到发现丈夫出轨，才知道原来是三个人的战场。

**发展：**
> 三儿叫林婉柔，是丈夫公司的实习生。年轻、漂亮、看起来人畜无害。但我不知道的是，她早就盯上了我丈夫。当我发现聊天记录时，整个人都懵了。更让我心寒的是，丈夫说我"不够关心他"，说我"太强势"。我没有哭闹，只是默默打开了手机录音。

**高潮：**
> 在婆婆六十大寿那天，我把录音放了出来。"儿子，你怎么能这样..."婆婆当场晕倒。林婉柔试图解释，但我早就收集了她在公司散布谣言的证据。丈夫跪下来求我，我看着他，忽然觉得无比陌生。

**结尾：**
> 离婚后，我用分到的财产开了自己的工作室。一年后，我的品牌估值千万。前夫想复合？我笑了笑，他不知道的是，我已经有男朋友了。比他年轻，比他有钱，比他更爱我。

**金句：**
- "你以为我好欺负，却不知道我只是不想跟你计较。"
- "离婚不是失败，是重生。"
- "有些男人，就像过期食品，不扔掉只会臭了整个冰箱。"

---

### 示例二：因果报应

**标题：** "他为了小三净身出户，三年后跪求前妻复婚"

**开头：**
> 婚姻就像一双鞋，合不合脚只有自己知道。当我发现丈夫为了那个女人愿意放弃一切时，我就知道，这双鞋该扔了。

**发展：**
> 丈夫叫张伟，我们结婚十年，有两个孩子。他出轨的对象叫王雨甜，是个刚毕业的大学生。她 cute、年轻、有活力。张伟说他找到了真爱，要和我离婚。我什么都没说，只是把两个孩子送去了我妈家，然后悄悄把房子做了财产保全。

**高潮：**
> 三年后，张伟找到我，说王雨甜卷钱跑了，他的公司也倒闭了。他跪下来求我原谅，求我给孩子一个完整的家。我看着他，忽然觉得很可笑。三年前他抛弃我们母子的样子，我还记得清清楚楚。

**结尾：**
> "张伟，你以为我还是三年前的那个我吗？"我笑了笑，"我现在一个人过得很好。"我关上门，把他隔绝在门外。门外的他在哭，门里的我在笑。

**金句：**
- "出来混，迟早是要还的。"
- "有些错犯了，就再也回不去了。"
- "你抛弃的 不是妻子，是一个家。"

## Usage

**触发方式：**
```
写言情出轨文
写言情复仇文
写言情逆袭文
写一个原配反击的故事
写一个渣男倒霉的故事
```

**参数：**
- `-theme`: 出轨/复仇/逆袭/真爱（默认随机）
- `-tone`: 虐心/爽文/温馨（默认爽文）
- `-length`: 短篇/中篇/长篇（默认短篇1000字）

**示例：**
```
写一个言情短篇，主题出轨，风格爽文
写一个原配逆袭的故事，2000字
写一个女主复仇的言情文，be结局
```
